# Anuki Gallery

ფოტოების ალბომები, ონლაინ ფოტო-რედაქტორი და ფოტოგრაფიის ტუტორიალი — ქართულად, ერთ სტატიკურ საიტში. სერვერი არ სჭირდება: ყველაფერი ბრაუზერში მუშაობს, ფოტოები შენს მოწყობილობაზე ინახება (IndexedDB).

## გვერდები

| ფაილი | რა არის |
|---|---|
| `index.html` | ალბომები: შექმნა, გადარქმევა, წაშლა, ფოტოების ატვირთვა (drag & drop), ჩამოტვირთვა |
| `editor.html` | რედაქტორი: სინათლე/ფერი (სიკაშკაშე, ექსპოზიცია, კონტრასტი, ნათელი/ჩრდილები, ტემპერატურა, ტონი, სატურაცია, ვიბრანსი, hue, სიმკვეთრე), 15 პრესეტი, ეფექტები (ვინიეტი, grain, fade, blur, ინვერსია), კადრირება პროპორციებით, ზომის შეცვლა, მობრუნება/არეკვლა/გასწორება, ფონის დაბლარვა (ფუნჯი / ოვალი), ტექსტი, ხატვა, ჩარჩო და padding, undo/redo, ექსპორტი JPEG/PNG/WebP, ალბომში შენახვა |
| `tutorial.html` | ფოტოგრაფიის 14 გაკვეთილი: კამერა, ექსპოზიციის სამკუთხედი, დიაფრაგმა, ჩამკეტი, ISO, კომპოზიცია, სინათლე, თეთრის ბალანსი, ფოკუსი, პორტრეტი, პეიზაჟი/ქუჩა, ტელეფონი, დამუშავება, შეცდომები |

## გაშვება

ლოკალურად (ES-მოდულების გამო `file://`-დან არ გაიხსნება, პატარა სერვერი სჭირდება):

```bash
python3 -m http.server 8000
# გახსენი http://localhost:8000
```

GitHub Pages: Settings → Pages → Source: `main` branch, root. საიტი გაიხსნება `https://<username>.github.io/Anuki-gallery/`.
